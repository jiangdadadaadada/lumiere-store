# LUMIÈRE · 全球化成人用品跨境独立站

高端 / 私密 / 健康生活方式定位。**IP 自动定位 → 语言 / 货币 / 支付 / 内容全链路切换**。静态前端 + Cloudflare Worker 后端，站点零成本。

## 核心能力

- **IP 自动定位**：访问者 IP → 国家码 → 自动匹配语言、货币、支付方式、文字方向。用户可手动覆盖（持久化到 localStorage）。
- **41 种语言**：覆盖亚洲/欧洲/中东/非洲/中亚主要语种（中英日韩德法西葡俄阿 + 意荷波瑞丹挪芬捷希匈罗乌塞土印地孟加拉马拉地泰米尔马来菲律宾高棉缅甸斯瓦希里南非荷兰哈萨克波斯希伯来乌尔都等）。每语种 119 条界面文案 + 12 商品名/描述 + 81 属性词条，全部翻译。
- **RTL 支持**：阿拉伯语 / 希伯来语 / 波斯语 / 乌尔都语 4 种自动切换从右到左布局。
- **121 种货币**：全球六大区域分组（常用/欧洲/亚太/中东非洲/美洲），自动换算，正确处理零小数（日元/韩元）、3 位小数（第纳尔类）等。
- **151 个国家/地区**：语言/货币/支付/旗帜完整映射，结账页可按国家选择。
- **地区支付**：按国家匹配 COD（106 个 COD 地区）/ 银行卡 / 加密货币。
- **完整后端 + 后台管理**：地理定位、订单 CRUD、支付回调验签、库存扣减、经营统计、**商品 CRUD（增删改 + 图片上传）**；配可视化管理后台 `admin.html`。
- **完整商品详情页**：左侧多角度画廊（缩略图切换，实拍 + AI 补图，9 款共 20 张），右侧购买区；下方五个标签页——**商品详情**（220–320 字长描述，中英各一套）/ **规格参数**（材质·尺寸·噪音·防水·供电·包装尺寸·件重·产地·包装清单 9 项）/ **使用与保养**（清洁·收纳·电池·润滑 4 张卡片）/ **配送与隐私**（隐蔽包装·时效·隐私 3 张卡片）/ **常见问题**（3 条问答）；页面底部是相关推荐（同分类优先，可直接加购）。所有文案 41 语言齐备，词条在 `assets/i18n-detail.js`（独立补丁文件，30 词条 × 41 语言）。
- **商品可后台上传**：后台「商品管理」可直接新增/编辑/删除商品、上传图片（自动压缩为 base64 存储），商城刷新即生效；无需改代码。
- **后台中英双语录入 → 前端全语种呈现**：后台用中文或英文录入即可（商品名/描述各留中英两栏），上架后访客看到的名称与货币由 IP 国家决定——中文站显示中文名，其余 40 种语言回退英文名（内置 12 个 SKU 有全 41 语翻译），价格按当地货币换算。
- **后台界面上中英一键切换**：右上角 `EN / 中文` 按钮切换运营界面语言，选择记忆在 localStorage。
- **联系方式与站内聊天**：`contact.html` 联系页（站内聊天 / 邮件 / 在线时间三渠道 + 留言表单 + 4 条 FAQ），全站右下角浮动聊天窗——**默认收起，只有点气泡才展开，刷新不恢复展开状态**；访客消息进后台「客服消息」收件箱，可直接回复，前台 4 秒轮询接收，关闭状态 20 秒轮询未读红点。后台可一键关掉聊天入口。
- **支付开关**：后台「站点设置 → 支付开关」可分别开关 在线下单总开关 / 货到付款 / 银行卡 / 加密货币。前端按开关实时过滤渠道：
  - 商品详情页仍有可用渠道 → 正常显示「提交订单 / 加入购物袋」；**全部关掉 → 两个按钮与数量选择整体消失，换成「联系客服」（点击直接唤起站内聊天，聊天关了则跳联系页）**；
  - 结账页无可用渠道 → 显示停用提示并禁用下单按钮；**渠道恢复后按钮自动解除禁用**。
- **下单语义为「提交订单」**：商品详情页购买按钮、结账页主按钮统一为「提交订单」（非「立即支付」）；提交后订单进入**待审核**队列，审核通过再安排付款。
- **后台订单状态机（7 状态）**：待审核 `pending` → 已审核 `approved` → 待付款 `awaiting_payment` → 已付款 `paid` → 已发货 `shipped` → 已完成 `completed`，任一未终态可转「已取消」`cancelled`。后台订单管理页按状态分组标签（带实时计数），详情弹窗只显示**当前状态的合法下一步**按钮；非法流转后端直接 400 拒绝并返回 `allowed` 白名单。每次流转写入 `history`（状态 + 时间 + 说明），后台「状态流转记录」可读。
- **全球地址内置 + 详细地址必填**：内置 **250 个国家/地区 + 5327 个州省**（`assets/address-data.js`，源自 dr5hn/countries-states-cities-database），中国额外内置**省→市→区县三级码表**（源自 china-area-data，34 省市 / 市区县全量）。结账页按国家自动切换表单：
  - **中国**：国家 → 省 → 市 → 区/县 四级联动下拉，必须选到区/县；
  - **有州省数据的国家（229 个）**：州/省下拉选择 + 城市手填；
  - **其余国家**：州/省、城市均手填。
  - 必填 **收件人 / 邮箱 / 国家 / 州省 / 城市 / 详细地址 / 联系电话**，选填公寓楼层 / 邮编。详细地址至少 6 字且须写到门牌号；邮箱格式前后端双校验。任一缺项前端聚焦到具体字段、后端返回 400 + `field`。订单快照保存完整地址（含区/县、国家名），成功页与后台逐行回显。
- **真实邮箱**：邮箱做格式校验（前端正则 + 后端正则双校验），非法返回 400 + `field: email`。
- **商品规格尺寸逐项体现**：每个商品的结构化 `specs` 数组（`{k, v, vEn}`）在 6 处展示 —— 商品详情页右侧信息栏**逐行规格表**、「规格参数」页签（尺寸明细 / 其他参数两个分组）、商品卡片规格行、购物车条目、订单摘要、提交成功回显；下单时把规格**快照**进订单 `items[].specs`，后台订单详情可回溯下单当时的尺寸。已为 9 款真实商品写入 59 项规格（数据取自 1688 供应商申报值），规格键 15 种（长度/直径/最大直径/高度/宽度/体积/颜色/线长/件数/开口/版本/包装规格/净重/产地/材质）。
- **前后端数据同源**：地理数据从 `geo.js` 数据表自动生成 `geo-data.js` 供后端引用；地址数据由 `build-address-data.js` 从公开数据集生成 `address-data.js` 并补齐 `geo.js` 的国家/货币表，两边永不漂移。

## 本地运行（完整前后端）

```bash
cd E:\LUMIERE
node server.js
```

访问 http://localhost:8080 （商城首页）。**后台管理：http://localhost:8080/admin.html**（仪表盘/订单/库存/设置）。

本地默认识别为 CN（中文界面）；后端接口：
- `GET /api/geo` — 地理定位
- `GET /api/currencies` — 货币表（156 种）
- `POST /api/order` — 创建订单（初始状态 `pending` 待审核；校验邮箱格式 + 姓名/国家/州省/城市/详细地址（≥6字）/电话必填，中国另需区/县；非法返回 400 与 `field`）
- `GET /api/order/:id` / `GET /api/orders` — 查询（`?status=` 按状态筛选，返回 `counts` 各状态计数）
- `PATCH /api/order/:id` — 更新订单状态（管理）；非法流转返回 400 + `allowed` 白名单
- `POST /api/payment/callback` — 支付回调（验签 + 扣库存）
- `GET /api/stats` — 经营统计（订单/营收/状态分布/国家分布/低库存）
- `GET /api/stock` / `PATCH /api/stock/:id` / `PUT /api/stock/:id` — 库存查询/扣减/设置
- `GET /api/products` — 商品列表（商城前端与后台共用）
- `POST /api/products` / `PUT /api/products/:id` / `DELETE /api/products/:id` — 商品增改删（新增自动建库存）
- `GET /api/settings` — 站点设置（支付开关 / 联系方式 / 聊天开关）
- `PATCH /api/settings` — 修改设置（后台支付开关、联系方式）
- `POST /api/chat/message` — 访客发消息（无 sessionId 则新建会话；`type:"contact"` 为联系页留言）
- `GET /api/chat/messages?sessionId=` — 访客拉消息（前端 4 秒轮询）
- `GET /api/chat/sessions` — 会话列表 + 未读总数（后台）
- `GET /api/chat/session?id=` / `POST /api/chat/reply` / `PATCH /api/chat/read` / `DELETE /api/chat/session/:id` — 后台读会话/回复/标记已读/删除
- `GET /api/health` — 健康检查

> 纯静态预览也可用 `python -m http.server 8080`，但此模式无后端，IP 定位会走前端免费 API 兜底，下单为纯前端演示，站内聊天不显示（读不到 `/api/settings`）。

## 部署

1. **前端**：Cloudflare Pages 绑定整个目录，直接发布静态文件。
2. **后端 Worker**：
   ```bash
   wrangler d1 create lumiere-db          # 建库，ID 填入 wrangler.toml
   wrangler d1 execute lumiere-db --file=schema.sql
   wrangler secret put PAYMENT_SECRET     # 支付回调验签密钥
   wrangler deploy                        # 部署 worker.js + backend-core.js
   ```
3. **路由**：Pages 配置 `/api/*` 回源到 Worker。前端 `fetch('/api/geo')` 自动拿到 Cloudflare 的国家码。

## 扩展语言 / 替换商品

- **加语言**：在 `assets/i18n/` 新建 `<code>.js`（照 zh.js 结构，119 ui + 12 products + 81 vocab + meta），在 7 个 HTML 的 script 列表、`app.js` 的 `LANG_GROUPS`、`geo.js` 的 `LANG_FALLBACK` 三处登记；另在 `_shell/` 补该语言的联系/聊天词条 JSON 并重跑 `build-i18n-shell.js`。
- **换商品**：推荐直接在后端「商品管理」增删改（`admin.html` → 商品管理），商城刷新即生效。也可编辑 `assets/products.js` 的 `PRODUCTS` 作静态兜底（无后端时使用）。
- **商品多语言（当前实现）**：后台录入「商品名称（中文）+ 商品名称（英文）」两栏，前端按四级回退取词——
  1. 商品自带 `i18n[lang]` 覆盖（预留，接翻译服务后用）；
  2. 语言包 `I18N[lang].products[sku]`（内置 12 个 SKU 有全 41 语翻译）；
  3. 后台新增商品：`lang==='zh'` 取中文字段，其余语言取英文字段（无英文则回退中文）；
  4. 兜底中文语言包。

  权衡：后台只录中/英两种，其余 39 种语言显示英文名——这是运营成本与覆盖面的平衡点。若某语言要地道文案，在该语言包 `products` 里补该 SKU 即可（第 2 级优先于第 3 级）。
- **后台界面语言**：后台只有中/英两套界面（`admin.html` 内 `AI_DICT` 词条表 + 文本节点翻译），与商城面向访客的 41 语言无关。加词条只需往 `AI_DICT` 里补一行"中文:英文"，英文值不可重复（反向翻译靠它）。
- **改国家/货币/汇率**：只改 `assets/geo.js` 的 `CURRENCY_DATA` 和 `COUNTRY_DATA` 两张数据表，然后跑 `node gen-geo-data.js` 重新生成后端共享数据。（前后端共用同一数据源，避免映射漂移。）
