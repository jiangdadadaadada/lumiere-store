# LUMIÈRE 商品采集器

从任意电商平台（1688 / 淘宝 / 拼多多…）采集商品，**自动转白底图**，直接入库 LUMIÈRE。

---

## 安装（一次性）

双击 **`E:\LUMIERE\安装采集插件.cmd`**

脚本会自动：关掉 Edge → 写入扩展 → 重开 Edge。**不需要手动做任何操作。**

> Edge 必须完全退出才能写入成功（Edge 退出时会覆写配置）。脚本已经帮你处理了。

装好后：
- 到 `edge://extensions` 能看到「LUMIÈRE 商品采集器」
- 点「详细信息」→ 打开「在工具栏上显示」（不然找不到图标）

**扩展代码更新后**，再双击一次那个 cmd 即可（它会复用同一个扩展 ID，不会重复安装）。

---

## 使用（就三步）

1. 打开商品**列表页**（店铺页 / 搜索结果页）
2. 点工具栏上的 **L** 图标
3. 点 **「采集当前页并入库」**

等它跑完，商品就已经在 LUMIÈRE 里了，图片是白底。

弹窗里只有一个「最多抓 N 款」的数字框，默认 60。

### 它会自动做什么

- 滚动页面加载全部商品
- 逐个打开详情页，补全**完整图集**和描述
- 校验详情页确实是商品页（URL 跳回首页 / 404 时不会把站点文案当商品名）
- 下载图片 → 本地 AI 抠图 → 合成纯白底（rembg u2netp，不联网、不花钱）
- 写进 `.data/db.json`，图片存进 `assets/img/collected/`

---

## 采集的商品在哪

| 阶段 | 位置 |
|---|---|
| 采集后（还没入库） | 只在扩展内存里，弹窗显示结果 |
| 入库后 · 商品记录 | `E:\LUMIERE\.data\db.json` → `products` |
| 入库后 · 白底图片 | `E:\LUMIERE\assets\img\collected\` → WebP |
| 前台查看 | `http://127.0.0.1:8080` → 后台 `admin.html` |

入库的商品带 `sourceUrl`（来源链接）和 `collectedAt`（采集时间），可追溯。

## 常见问题

**图标找不到**
`edge://extensions` → LUMIÈRE 采集器 → 详细信息 → 打开「在工具栏上显示」。

**弹窗提示「本地服务未启动」**
采集需要 LUMIÈRE 服务在跑。双击 `E:\LUMIERE\启动服务.cmd`（如果还没建，用 `node server.js` 启动）。

**采到 0 个商品**
说明这个页面的商品链接结构不认识。换个店铺页试试，或者把网址发给我，我加一条解析规则。

**入库失败 / 图片没变白底**
看 `E:\LUMIERE\tools\out\server.log` 末尾的错误信息。

## 技术说明

| 文件 | 作用 |
|---|---|
| `manifest.json` | MV3 清单，声明 `tabs` / `scripting` / `storage` 权限 |
| `background.js` | 调度：抓列表 → 逐页深采 → 分批入库（每批 8 个） |
| `inject.js` | 注入到目标页运行的解析器（天然带登录 Cookie，绕开平台反爬） |
| `popup.html/js/css` | 弹窗界面 |
| `icons/` | 图标 |

安装脚本 `tools/install_ext.js` 的原理：Chromium 把已装扩展记在
`<profile>/Secure Preferences`，并用 HMAC-SHA256 校验。脚本写入记录后重算校验值，
Edge 就会认这个解压缩扩展。幂等——重复安装复用同一个 ID。
