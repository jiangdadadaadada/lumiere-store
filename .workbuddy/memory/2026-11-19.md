### 关键技术发现（重要，下轮直接复用）
1. **Edge/Chromium 加载扩展：`--load-extension` 路径必须用正斜杠**
   `E:\LUMIERE\extension` 会**静默加载失败**（无任何报错），必须写 `E:/LUMIERE/extension`。
   这是本轮最大的坑，排查花了最久。
2. **MV3 的 SW 在 CDP 里类型是 `service_worker`**，不是 `background_page`。
   `background_page` 全是 Edge 内置扩展（Microsoft Voices / WebRTC / Edge Feedback 等），
   按 `_generated_background_page.html` 找会连错对象。
3. **扩展无法用 `chrome.runtime.sendMessage` 发给 SW 自己**（接收端不存在）。
   已把 background.js 的消息处理抽成 `handleCommand(msg)` 函数，SW 内部可直接调用。
4. **Secure Preferences 装解压缩扩展**：
   - 记录在 `extensions.settings`（location=4 为解压缩）
   - MAC 在 `protection.macs.extensions.settings.<id>`
   - 算法：HMAC-SHA256(seed, key + JSON.stringify(entry))，seed = Local State 的
     `os_crypt.encrypted_key` 经 DPAPI 解密（去掉 "DPAPI" 5 字节前缀）
   - **必须用独立新 ID**，复用模板 ID 会覆盖已装扩展
   - Edge 运行时会在退出时覆写 Secure Preferences → 装完必须完全退出 Edge 再开
5. **Playwright 自带 chromium（ms-playwright/chromium-1169）缺 DLL，跑不起来**，别再试。
